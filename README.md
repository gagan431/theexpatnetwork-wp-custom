# The Expat Network — Custom WordPress Build

Custom WordPress code repository for theexpatnetwork.org.

## Scope

This repo stores:

- Custom WordPress plugins
- Codex CLI prompts
- Product specs
- QA checklists
- Rollback notes
- Plugin release ZIPs

## Do Not Commit

- WordPress core
- Production database backups
- Production uploads
- Cache files
- wp-config.php
- Credentials or API keys
- Full site backup archives
