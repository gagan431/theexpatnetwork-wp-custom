# KPI Framework

North star: meaningful next-step completions.

.org: pathway starts, pathway→tool clicks, official-source clicks, programme actions, registrations, organisation enquiries, specialist-help requests.

.de: tool starts/completions, completion rate, return-to-.org clicks, privacy/performance errors.

LinkedIn: qualified profile views, saves/comments from target audience, institutional conversations, click-throughs.

Instagram: saves, shares, profile visits, click-throughs, follower quality.
