# Research & Source Policy

Source hierarchy:
1. primary official authority / law / official programme
2. direct institutional source
3. high-quality industry/professional source
4. provider site for provider claims
5. LinkedIn/Reddit/community for pain-point evidence only

High-volatility facts must be re-verified before publication.
Show `Last verified: YYYY-MM-DD` on relevant pages/tools.

SETU/SarvaSetu: monitor, but do not state ownership/endorsement/affiliation beyond what primary official sources support.
