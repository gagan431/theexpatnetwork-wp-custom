# THE EXPAT NETWORK — Canonical Source Pack

This directory contains the current canonical strategy and operating source files for THE EXPAT NETWORK.

## Source precedence

When sources conflict, use this order:

1. Current official / primary source for factual rules
2. Current canonical TEN strategy files in this directory
3. Accepted ADRs
4. Current domain, workflow and product specifications
5. Source registry
6. Live implementation / current code
7. Latest research dossier
8. Legacy audits and older repository strategy documents
9. AI-generated suggestions

## Important legacy warning

The repository also contains older documents such as `docs/MASTER_PRODUCT_STRATEGY.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md` and the root `README.md`. Those files reflect an earlier acquisition/relocation-services framing and must not silently override this canonical source pack.

In particular, older statements such as:

- the primary business being relocation counselling / job-offer review services;
- every tool needing to connect to a service or lead-capture flow;
- qualified relocation and placement leads as the primary success metric;
- a generic Content → Tools → Services → Partnerships architecture;

are legacy framing unless explicitly re-adopted through a new decision record.

## Core no-go boundaries

Do not build or imply:

- generic job marketplace or ATS;
- employer/candidate dashboards;
- AI auto-apply;
- generic visa bot;
- fake partner relationships;
- unsupported statistics or outcomes;
- regulated advice or official determinations by TEN.
