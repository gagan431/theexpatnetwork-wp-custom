# Germany Job Offer Checker v1.0.0 — Product Spec

## Objective

Upgrade the existing Germany Job Offer Checker into the primary lead-generation tool for theexpatnetwork.org.

## Funnel

Free checker → result → Germany Offer Reality Review → relocation clarity call → partner/referral funnel.

## Must Preserve

- Shortcode: [germany_job_offer_checker]
- Client-side calculations where practical
- No external APIs
- No accounts
- No database tables
- No sensitive data storage

## Required Changes

- Improve result hierarchy.
- Put Blue Card / salary-readiness estimate near the top.
- Add visible educational disclaimer.
- Add CTA card after result.
- Link CTA to /services/germany-job-offer-review/.
- Keep mobile layout clean.
- Scope CSS.
- Version bump to 1.0.0.

## Legal Boundary

This tool must present readiness estimates only. It must not claim legal advice, immigration advice, visa approval, guaranteed eligibility, or zero rejection risk.
