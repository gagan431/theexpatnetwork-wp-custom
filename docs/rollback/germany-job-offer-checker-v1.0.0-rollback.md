# Germany Job Offer Checker v1.0.0 — Rollback Plan

## Trigger Rollback If

- Plugin causes fatal error.
- Shortcode stops rendering.
- Tool result does not calculate.
- CTA links are broken.
- Mobile layout is unusable.
- Legal-risk copy appears.

## Rollback Steps

1. Deactivate Germany Job Offer Checker v1.0.0.
2. Delete the v1.0.0 plugin folder if needed.
3. Reinstall the previous known-good plugin ZIP.
4. Activate the previous plugin version.
5. Clear WordPress/page cache.
6. Test the page containing [germany_job_offer_checker].
7. Confirm previous behavior is restored.
