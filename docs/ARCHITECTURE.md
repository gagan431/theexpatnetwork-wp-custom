# The Expat Network — Architecture

## Layer 1 — Content

Examples:

- country guides
- visa guides
- salary guides
- employer guides
- relocation guides

Purpose:

SEO acquisition.

## Layer 2 — Tools

Examples:

- Germany Job Offer Checker
- Salary Calculator
- Cost of Living Calculator
- CV Readiness Checker
- Visa Readiness Checker

Purpose:

Lead qualification.

## Layer 3 — Services

Examples:

- Job Offer Review
- Relocation Counselling
- CV Review
- LinkedIn Review
- Salary Review

Purpose:

Revenue generation.

## Layer 4 — Partnerships

Examples:

- recruiters
- employers
- relocation partners
- language schools
- insurance providers

Purpose:

Scalable monetization.

## WordPress Rules

- no user accounts
- no dashboards
- no marketplace
- no complex SaaS infrastructure
- stateless tools preferred
- low maintenance preferred

## Development Rules

Every feature must answer:

1. Does it generate qualified leads?
2. Does it improve placement outcomes?
3. Does it support relocation services?
4. Can it be maintained by a solo founder?

If not, reject it.
